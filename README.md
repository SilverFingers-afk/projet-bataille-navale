# Projet Bataille Navale

Ce projet a pour objectif de créer un jeu de bataille navale sur python, utilisant divers outils vus en classe tels que les fonctions de tests, les classes ou encore l'outil GitHub et Visual Studio Code.

Pour démarrer le projet, il faut lancer le fichier main qui se trouve dans SRC. Une fois lancé, les instructions apparaissent : il faut entrer les coordonnées où l'on souhaite tirer. Une icône de bombe apparaît si l'on touche un bateau, et ces icônes se transforment en l'icône du bateau lorsque ce dernier est coulé. Un message personnalisé apparaît également.

A la fin de la partie, la grille finale s'affiche avec le nombre d'essais.
